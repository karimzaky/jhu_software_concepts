PERSONAL WEBSITE — MODULE 1
===========================

Description
-----------
This project is a personal website built with Python, Flask,
HTML, and CSS. It includes a homepage with professional information,
a contact page, and a projects page.

The application uses a Flask blueprint to organize its page routes and
HTML templates to display the website content.


SYSTEM REQUIREMENTS
===================

- Python 3.10 or newer


INSTALLATION
============

1. Open a terminal and navigate to the module_1 folder:

   cd module_1

2. Create a Python virtual environment:

   python3 -m venv .venv

3. Activate the virtual environment.

   macOS

   source .venv/bin/activate

4. Install the required packages:

   python -m pip install -r requirements.txt


RUNNING THE WEBSITE
===================

Start the Flask application with:

python run.py

Open a web browser and navigate to:

http://localhost:8080


AVAILABLE PAGES
===============

Home:
http://localhost:8080/

Contact:
http://localhost:8080/contact

Projects:
http://localhost:8080/projects

To stop the application, return to the terminal and press Control+C.
